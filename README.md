# PHISHING X-RAY (PHISH-X)

An Explainable AI-Based Phishing URL Detection System.

## Project Overview

PHISH-X is an AI-powered security system designed to detect phishing URLs and distinguish them from legitimate URLs.

The system uses Logistic Regression to classify URLs and applies Numerical Methods to optimize model parameters.

It also provides explainability by identifying the URL features that contribute to the prediction.

## Main Objectives

- Detect phishing and legitimate URLs.
- Apply Numerical Optimization Methods.
- Compare Gradient Descent and Newton's Method.
- Explain model predictions.
- Evaluate model performance and robustness.
